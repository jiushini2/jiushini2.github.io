无线串口日志系统

摘要：关于CH570Q的无线串口，轻松实现无线烧录还有日志打印

原理图：

PCB

在拿到板子后使用恒温加热台外加电烙铁焊接会方便很多，再确认焊接无连锡还有电源短接后我们就可以对两个模块分别进行烧录

那就需要MounRiver Studio Ⅲ生成对应模块的HEX文件，再使用WCHISPStudio进行串口烧录

烧录完成后，两者靠进上电进行配对，直至二者灯亮

之后我们就可以使用这组模块实现无线烧录还有日志打印

首先是无线烧录：

在这里，我拿C8T6举例，首先是关于单片机的BOOT在这里补充一下，我们在串口烧录时，要把BOOT0置高电平，BOOT1置低电平，在烧录完成后再把BOOT0换回低电平，在这里可能会觉得会有些麻烦，烧录还有代码启动要换跳线帽是有些复杂，后续我们可以自画一个板子，在BOOT引脚上置放一个开关，那样就会方便许多

再把BOOT引脚做好切换后，我们首先要在工程里编译生成HEX文件

再拿到HEX文件后，我们在使用FlyMcu.exe 进行串口烧录

烧录完成后记得复位BOOT再按一次复位键，就可以实现无线烧录，效果例子;

关于这个我在天空星上做了测试，源码，还有GITHUB开源的GitHub - armink/EasyLogger: An ultra-lightweight(ROM<1.6K, RAM<0.3k), high-performance C/C++ log library. | 一款超轻量级(ROM<1.6K, RAM<0.3k)、高性能的 C/C++ 日志库 · GitHub

日志打印系统：

下载后移入对应的工程融合

在烧录后我们需要用到VAFA上位机查看，效果如下

不同的数据不同的颜色，还带有时间戳，日志的查看更加便捷
